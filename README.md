# TikTok 直播网络抖动：先分清是本地宽带、推流设置还是跨境链路的问题，再用专线加独享IP稳住码率

直播间画面卡成PPT、观众刷"卡了"、码率曲线像心电图——这类问题里，网络抖动是最常见也最容易被误判的原因。很多人第一反应是换手机、换电脑，结果钱花了，问题还在。这篇文章按"先查免费的、再查要花钱的"顺序，把 TikTok 直播网络抖动的排查过程拆开讲清楚，最后再聊什么时候真的需要上专线。

## 抖动到底是什么，卡在哪一环

抖动（Jitter）指数据包到达时间的波动。推流时数据包本该以稳定的间隔发出去，如果这一秒是 20ms、下一秒变成 200ms，编码器和推流队列就会堵住，画面表现就是掉帧、马赛克、音画不同步。

和它一起要看的是另外三个指标：

- **RTT（往返延迟）**：你的设备到 TikTok 服务器一个来回的时间，一般建议控制在 200ms 以内；
- **丢包率**：丢了的数据包只能重传或者干脆放弃，TikTok 对丢包的容忍度大约在 2% 以下，理想状态是压到 0.5% 以内；
- **上行带宽**：直播吃的是上传不是下载。以 TikTok 官方推荐为例，720p 至少需要 3Mbps 的稳定上传，1080p 最好维持在 6Mbps 以上。

抖动控制在 30ms 以内是比较理想的状态。有做直播专线的行业文章给过一组对比：专线链路可以把抖动压在 ±10ms 以内，而普通宽带跑跨境流量时抖动动辄 ±50ms 以上——这就是很多直播间"宽带够快但就是卡"的原因。带宽大不代表稳，直播要的是持续、低波动的上行。

## 排查顺序：从免费到收费，一步步来

### 第一步：看推流软件的监控数据

不管你用 TikTok Live Studio 还是 OBS，都先打开数据面板，看三个数字：实时上传码率、丢包率、当前帧率。如果丢包率经常超过 1%，或者帧率明显低于设置值，问题基本可以锁定在网络链路上，而不是设备性能。

### 第二步：排除本地设备和系统负载

TikTok 官方的直播工作室故障排除指南说得很直接：大多数卡顿由系统过载引起，CPU、GPU、内存占用率到 100% 时就会出现。推流时打开任务管理器看一眼，CPU 长期在 80%-90% 以上，说明电脑本身已经是瓶颈。另外官方还建议关掉超频、拔掉不必要的外接设备、必要时换一个运营商的网络试试。

### 第三步：调推流参数，给带宽留余量

一个常用的经验是把码率设为实际上传带宽的 70% 左右。比如测速出来上传 10Mbps，推流码率选 6000~7000kbps 比较稳。TikTok 参考码率范围大致是 720p 用 3-5Mbps、1080p 用 6-10Mbps。如果网络本身有波动，主动降码率或降分辨率，比硬扛着让平台自动降画质要体面——至少卡顿是可控的。

### 第四步：测跨境链路，这一环最容易出问题

如果本地一切正常，参数也调过了，卡顿依旧，那问题大概率在跨境链路上。国内访问 TikTok 的路径会经过出口和中间节点，晚高峰拥堵、运营商国际出口波动、共享 IP 被他人占用，都会直接反映成抖动和丢包。这时候可以先换个时段测试做对照：如果只有晚上卡，白天不卡，基本就是链路拥堵；如果全天都抖，那就要看出口质量了。

> 直播间网络不稳定还可能带来另一个后果：TikTok 会检测 IP 异常。长期用不稳定节点直播的账号，更容易被判定为风险账号，进而被限流。所以跨境直播对网络的要求，不只是"不卡"，还包括出口 IP 的纯净和稳定。

## 共享带宽还是独享带宽

这是选套餐时最容易纠结的点，Mkcloud 知识库里的思路可以借鉴：间歇访问、短时上传按月流量选共享带宽；需要持续速率保证的，按配置速率评估独享带宽。

拿沪港入门套餐做个对比：共享版是 1核2G、200Mbps 峰值、1024GB 月流量、月付 288 元；独享版是 2核4G、5Mbps、不限流量、月付 388 元。注意 200Mbps 和 5Mbps 是两种完全不同的资源——共享带宽是峰值，不保证持续跑满；独享 5Mbps 不高，但胜在持续稳定。对直播来说，一个 200M 冲上去了但抖动大的链路，未必比一条稳稳当当的 5M 独享好用。TikTok 直播建议优先保证"稳定持续的上行"，其次才是峰值数字。

另外有个容易踩的坑：计量型套餐按上行、下行双向统计流量，达到额度后会暂停服务，需要自助购买流量重置或提交工单升级。直播团队估算流量时记得把双向都算进去，别只看推流那一头。

## 常见问题

**抖动多少毫秒算正常？**

30ms 以内是比较理想的状态。跨境公网抖动经常超过 ±50ms，专线可以把端内抖动压到 ±10ms 以内。注意端内值不等于你到 TikTok 服务器的全程抖动，但端内越稳，全程抖动的下限就越低。

**直播间卡顿一定是网络问题吗？**

不一定。TikTok 官方排查指南把系统过载排在第一位。正确顺序是：先看推流软件的丢包率和码率曲线，再看电脑 CPU 占用，最后才怀疑跨境链路。如果丢包率低、帧率正常但画面卡，多半是设备性能问题。

**用专线直播会被 TikTok 判定异常吗？**

专线提供的是独享、固定的出口 IP，这恰恰是降低风控风险的方向——TikTok 检测的是 IP 不纯净、频繁跳变这类异常，独享 IP 比共享节点稳定得多。当然，账号安全还取决于你整体的运营行为，网络只是其中一环。

**IXP 专线 158 元/月和广港 IEPL 358 元/月怎么选？**

核心区别在接入方式：IXP 需要云厂网络前置，适合已经有云服务器的用户；广港 IEPL 是直连款，入口选择更多（含八线动态 BGP），端内延迟 1~2ms，适合华南本地的直播团队。预算紧、有云资源就选 IXP，想要开箱即用和更低延迟就选 IEPL。

**1TB 月流量够直播多久？**

按 1080p（约 6Mbps 码率）估算，一小时上行流量约 2.7~3GB，再算上下行流量统计，1TB 大约支撑每天 3~4 小时、每月 20 多场的单人直播。团队多直播间建议直接上 6TB 档。
